Study area 01

HTML Fundamentals

HTML provides the structure of a webpage. These study cards cover the language's building blocks and common ways to organize and connect content.

↑ Back to categories

Building blocks

HTML elements and tags

An HTML element is a building block of a webpage. Most elements use an opening tag, content, and a closing tag.

Example HTML

<p>Welcome to my webpage!</p>

Welcome to my webpage!

Remember this: The whole example is a paragraph element; <p> and </p> are its tags.

Document structure

What belongs in the body?

The <body> element contains the content displayed in the browser window, such as headings, paragraphs, images, and links.

Simplified document

<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello!</h1>
    <p>Welcome.</p>
  </body>
</html>

Remember this: The <head> stores document information; the <body> contains visible page content.

Attributes

Adding information to elements

Attributes provide additional information about an HTML element. They appear in the opening tag, often as a name and a value.

Example attribute

<a href="about.html" title="Learn more">
  About us
</a>

href identifies the destination; title provides advisory information.

Remember this: title="Learn more" is an attribute, not a CSS declaration.

Void elements

Elements without closing tags

Some HTML elements don't wrap content and don't have a separate closing tag. Examples include <img>, <br>, and <hr>.

Examples

<img src="photo.jpg" alt="Campus building">
<br>
<hr>

Remember this: These are called void elements in HTML. You may also see them described as “self-closing” in introductory materials.

Links and navigation

Where can links go?

Links can lead to another page on your website, an external website, or a particular section of the current page.

Three destinations

<a href="about.html">Internal page</a>
<a href="https://example.com">External site</a>
<a href="#contact">Page section</a>

A section link uses the destination element's id.

Remember this: An anchor link such as #contact jumps to an element with id="contact".

Lists

Ordered vs. unordered lists

An ordered list (<ol>) presents items in a meaningful sequence. An unordered list (<ul>) groups items without implying a sequence. Both use <li> for each item.

How they appear

Ordered
  1. Plan
  2. Build
  3. Publish
Unordered
  • HTML
  • CSS
  • JavaScript
<ol><li>First</li></ol>
<ul><li>Item</li></ul>

Remember this: Choose <ol> when order matters; choose <ul> when it doesn't.

Website organization

Folders and directories

Websites organize files into folders, also called directories. This makes it easier to keep pages, images, and stylesheets organized.

Example folder structure

my-website/
├── index.html
├── about.html
├── css/
│   └── styles.css
└── images/
    └── logo.png

Remember this: A directory is another name for a folder. File paths tell the browser where resources are located.

Study area 02

CSS Fundamentals

CSS controls how HTML elements look and how they are positioned. Review the box model, declarations, colors, and common rules that affect a webpage's appearance.

↑ Back to categories

Box model

Content, padding, border, and margin

Every HTML element has a rectangular box. Padding adds space inside the border; margin adds space outside it. The border surrounds the padding and content.

The CSS box model

Margin
Border
Padding
Content

Remember this: Padding is between the content and the border. Margin is outside the border.

CSS declarations

Properties, values, and inline CSS

A CSS declaration pairs a property with a value. CSS can be written in a stylesheet or directly in an element's style attribute, which is called inline CSS.

Property and value

color: #000000;

color is the property; #000000 is the value (black).

Inline CSS example

<span style="color: #000000;">Text</span>

Remember this: style is an HTML attribute; color: #000000; is a CSS declaration inside it.

Shorthand values

Four sides, clockwise

For properties such as margin and padding, four values are applied in clockwise order: top, right, bottom, left.

Example shorthand

padding: 10px 20px 30px 40px;
Top · 10pxRight · 20pxBottom · 30pxLeft · 40px
CONTENT

Remember this: Think of a clock: top → right → bottom → left. The four-value pattern applies to margin and padding, not to the values of the border shorthand.

Positioning

Relative and absolute positioning

position: relative moves an element relative to where it would normally appear. position: absolute positions an element relative to its nearest positioned ancestor, if one exists.

Relative positioning

Normal position
Moved right and down
.example {
  position: relative;
  top: 15px;
  left: 20px;
}

Remember this: Relative positioning uses an element's own normal position as the starting point. Absolute positioning works differently.

Layering

Which element appears in front?

When positioned elements overlap, z-index helps control their stacking order. A higher value can place one element above another within the same stacking context.

Overlapping elements

z-index: 1
z-index: 2
.front {
  position: absolute;
  z-index: 2;
}

Remember this: z-index controls stacking order, but stacking contexts can affect which element appears on top.

Colors

RGBA and the alpha channel

RGBA describes a color using red, green, blue, and alpha. Alpha controls transparency: 1 is fully opaque and 0 is fully transparent.

Same color, different alpha values

1.0
0.7
0.4
0.15
background-color: rgba(30, 105, 190, 0.4);

Remember this: The “A” in RGBA stands for alpha, which controls transparency.

Debugging CSS

A missing brace changes the result

Browsers can ignore declarations when CSS syntax is broken. A misspelled word inside a comment doesn't affect styling, but a missing } can interfere with the rules that follow it.

Find the syntax error

body {
  background-color: #000000; /* black */

 div {
  color: #ffffff;
}

The body rule is missing its closing } before the div rule. The browser may apply the background but not the intended div color.

Remember this: Comments are ignored by the browser; missing punctuation in CSS rules can cause real syntax errors.

Study area 03

Forms & Inputs

HTML forms collect information in different ways. These cards explain how common controls behave and how a few important attributes affect what users can select or submit.

↑ Back to categories

Radio buttons

Choose one option from a group

Radio buttons are useful when a person should choose only one answer from a set of options. Buttons with the same name belong to the same group.

Example: Preferred class format

Choose one
<input type="radio" name="format" value="in-person">
<input type="radio" name="format" value="online">

Illustration only: the controls are disabled because this is a study guide, not a form to submit.

Remember this: Radio buttons sharing a name allow one selection at a time.

Checkboxes

Choose more than one option

Checkboxes let people select multiple independent choices. Unlike a radio group, checking one box doesn't automatically uncheck another.

Example: Topics to review

Select any that apply
<input type="checkbox" name="topics" value="html">
<input type="checkbox" name="topics" value="css">

Remember this: Checkboxes support multiple selections; radio buttons normally support one per group.

Dropdown menus

Single-select and multiple-select menus

The <select> element organizes choices into a menu. Normally, users choose one option. Adding multiple allows more than one selection.

Compare the two menus

One selection
Multiple selections
<select name="topic">...</select>
<select name="topics" multiple>...</select>

A multiple-select list may use Ctrl or Command to select separate options when enabled.

Remember this: The multiple attribute changes a select menu from one choice to potentially several.

Field attributes

What does disabled mean?

A disabled input cannot be edited or focused through normal keyboard navigation. Its value is not included when the form is submitted.

Example disabled field

<input type="text" value="Enrolled" disabled>

Remember this: Disabled fields cannot be changed by the user and are not submitted with the form.

Field attributes

What does readonly mean?

A readonly text input displays a value that users cannot normally edit. Unlike a disabled input, it can receive focus and its value is included in form submission when it has a name.

Example readonly field

<input type="text" name="course"
       value="IMED 1316" readonly>

Remember this: Readonly prevents normal editing but does not prevent the value from being submitted. It is not a security feature.

Quick comparison

Disabled vs. readonly

Both attributes can prevent a user from changing a text field, but they behave differently when the form is submitted.

Key differences

BehaviorDisabledReadonly
Normally editable?NoNo
Keyboard focus?NoYes
Value submitted?NoYes, if named

Remember this: If a field's value needs to be submitted, readonly and disabled are not interchangeable.
