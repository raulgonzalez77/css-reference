Understanding HTML relationships

CSS selectors often describe where elements appear in an HTML document. These terms make the examples below much easier to understand.

Parent

An element that directly contains another element.

Child

An element directly inside a parent element.

Descendant

An element anywhere inside another element, even several levels down.

Ancestor

Any element that contains another element, directly or indirectly.

Sibling

Elements that share the same parent.

Nested

HTML elements placed inside other HTML elements.

Example HTML
<div>
  <p>First paragraph</p>
  <section>
    <p>Nested paragraph</p>
  </section>
</div>

The div is the parent of the first p and the section. Both paragraphs are descendants of the div, but only the first is its direct child. The first p and section are siblings.
